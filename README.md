# Guessing Game 

A simple number guessing game built in C++ using Mersenne Twister

## What it does
Picks a random number between 1 and 100.
You guess until you get it right. It tells you if you're too high or too low.

## How to run

**Compile:**
g++ main.cpp -o guessing-game

**Run:**
./guessing-game
